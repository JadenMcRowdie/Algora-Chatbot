# 📚 Algora AI Chatbot

## 🧠 Overview

**Algora** is an educational chatbot designed to guide users through the fundamentals of Artificial Intelligence (AI). Developed by Tech-Hub using Voiceflow, Algora offers interactive, jargon-free explanations, real-world examples, and multimedia support to make AI learning accessible to everyone — especially youth.

---

## 🎯 Purpose

In today’s digital world, AI is embedded in our daily lives — often without us realizing it. Algora was created to bridge this knowledge gap by helping users understand:

- What AI is and how it works  
- How AI is used across industries  
- Ethical considerations in AI  
- Where to learn more through bootcamp modules and curated resources  

Algora’s mission is to make AI education simple, engaging, and inclusive.

---

## 👥 Target Audience

Algora is built for:

- Curious individuals of all ages  
- Students and youth eager to explore tech  
- Anyone with internet access via smartphone or computer  

---

## 🌐 Deployment

Algora is accessible via:

- **Web**: A dedicated URL will be provided  
- **Chatbot Interface**: Hosted through Voiceflow  

---

## 🛠️ Tools Used

- **Voiceflow**: No-code platform used to build and train the chatbot  
- **Multimedia Support**: Diagrams, flow visuals, and charts  
- **AI Bootcamp Integration**: Links to course modules for deeper learning  

---

## 🧪 Training & Agent Instructions

Algora is powered by a multi-agent system, each with specific roles:

| Agent | Role |
|-------|------|
| 1     | Greet user, confirm AI-related query |
| 2     | Ask user for preferred industry focus |
| 3     | Explain core AI concepts (AI, ML, DL, NLP, etc.) |
| 4     | Recommend bootcamp modules and resources |
| 5     | Help user choose learning path (terminology, ethics, applications) |
| 6     | Teach AI ethics (bias, fairness, transparency) |
| 7     | Handle follow-up questions on AI fundamentals |
| 8     | Handle unrecognized or off-topic queries |
| 9     | Route user when switching topics |
| 10    | Manage session limits and suggest new topics |
| 11    | Provide industry-specific AI examples |
| 12    | Summarize AI applications across industries |
| 16    | End session with gratitude and resource summary |
